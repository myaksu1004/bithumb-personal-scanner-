# 코인 저점 상승 탐색기 v5

빗썸/업비트는 동일 코드로 실행하되 `EXCHANGE` 환경변수로 분리합니다.

- 빗썸: `EXCHANGE=bithumb` (기본값)
- 업비트: `EXCHANGE=upbit`
- 로컬: `pip install -r requirements.txt` 다음 `python app.py`
- Render: 저장소 파일을 교체하고 각 서비스 환경변수 EXCHANGE를 지정한 뒤 재배포.
- `/health`, `/api/config`, `/api/scan`으로 확인.

## 전략
- B형: 4시간봉에서 우측 2개 확정봉을 둔 스윙 저점 3개가 연속 상승하고 현재 종가가 최근 저점 위에 있을 때만 유효.
- A/C형: 보조 관찰만 허용.
- 15분/1시간봉으로 진입 타이밍 평가. 단기 약세는 B형 관찰을 유지하면서 진입을 보류.
- 구조손절 거리가 3.5% 초과면 진입 보류. 손절선을 임의로 올려 손절 폭을 축소하지 않음. 0.8%보다 좁으면 최소 폭을 적용하되 거래소 호가단위/슬리피지는 별도 확인 필요.
- 저항선에 기반한 손익비가 1.5 미만이거나 저항이 확인되지 않으면 진입 검토 불가.

## 주의
- 시세 데이터만 조회하며 자동 주문하지 않습니다.
- 과거 백테스트 및 실시간 API 호출 검증은 별도 필요합니다.
- Render 무료 플랜은 호출 제한/타임아웃이 발생할 수 있습니다.
- `/api/scan`은 거래대금 상위 일부만 분석하므로 모든 상장 코인을 찾는 것은 아닙니다.
- 현재 상태는 요청 시 계산하며 7/14일 추적을 위한 영구 저장소는 포함하지 않습니다.
