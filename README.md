# 코인 저점 상승 탐색기 v5.1

## 업데이트
- B형(4시간봉 확정 저점 상승) 주력, A/C형은 보조 관찰.
- 매도 압력 0~100 별도 표시: 24시간 하락률, 최근 고점 하락률, 음봉 RVOL, MACD/RSI, 연속 음봉.
- 급락+거래대금 급증 등 조건에서는 B형 구조가 살아 있어도 진입 보류.
- 구조 점수에 최근 급락과 지지선 접근을 반영. 점수는 수익 확률이 아님.
- 손절 기준: 실제 확인된 지지 아래 버퍼를 적용. 손절폭이 너무 넓거나 ATR 대비 너무 좁으면 신규 진입 보류. 구조 손절을 억지로 당기지 않음.
- 목표가는 확인된 저항선 기준. 매수 자동 실행 없음.

## 배포
1. GitHub 저장소의 루트에서 `app.py`, `strategy_config.json`, `requirements.txt`, `render.yaml`, `README.md`를 교체합니다.
2. Render 환경변수 `EXCHANGE`를 거래소에 맞게 지정합니다.
3. `/health`에서 version=v5.1, exchange를 확인하고 `/api/scan`을 실행합니다.
4. 기존 `app_fixed.py`나 오래된 zip은 앱 구동에 사용되지 않습니다. 정상 배포 확인 후 삭제하세요.

## 주의
- 실제 거래소 호출 및 과거 데이터 백테스트는 이 패키지 제작 과정에서 검증하지 않았습니다.
- Render 무료 플랜에서 속도 제한/타임아웃이 발생할 수 있습니다.
- 스캔은 거래대금 상위 일부 종목만 분석하며, 7일 추적용 영구 저장소는 아직 없습니다.
- Risk/Pressure 점수는 휴리스틱이며 손실 가능성이나 실제 체결가를 보장하지 않습니다.
